## What is and is not here

Flare Therapeutics runs **no developer program**. There is no product API, no developer portal, no
API documentation, no SDK, no CLI, no sandbox, no status page and no API pricing. The only
machine-readable surface reachable without credentials is the WordPress REST content API behind
www.flaretx.com, which serves the corporate news archive, pages, media library and search.

If you are an agent looking for a Flare Therapeutics *product* API: there is not one. If you are
looking for the company's news, publications or scientific posters as structured data: use the
content API below.

## How to call it

- Base URL: `https://www.flaretx.com/wp-json`
- Auth: none. Every catalogued operation is an anonymous GET.
- Pagination: `page` + `per_page` (max 100); read `X-WP-Total` / `X-WP-TotalPages` and the RFC 8288
  `Link` header. `per_page` above 100 is a 400, not a clamp.
- Incremental sync: `modified_after` (ISO 8601) on posts, pages and media.
- Payload control: `_fields` to trim (the default post carries ~20KB of Yoast markup), `_embed` to
  inline featured media and terms.
- Errors: WordPress envelope `{code, message, data:{status}}` — NOT RFC 9457 problem+json.
- Courtesy: robots.txt advertises `Crawl-delay: 10`. No rate-limit headers are returned; honor the
  crawl delay.

Useful calls:

- Latest news: `GET /wp/v2/posts?per_page=20&_fields=id,date,slug,title,link`
- Press releases only: `GET /wp/v2/posts?categories=8` (Press Release), or `categories=3` (News)
- Scientific posters and presentations:
  `GET /wp/v2/media?media_type=application&per_page=100&_fields=id,date,slug,mime_type,source_url`
- Search everything: `GET /wp/v2/search?search=FX-909`
